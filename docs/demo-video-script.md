# MindSpace Demo 视频脚本

建议时长：2 到 3 分钟。

录制方式建议：手机录屏。最稳的展示方式是先启动后端，再用手机打开 Expo Go 扫码进入移动端；如果 Expo Go 不方便，也可以用手机浏览器访问 `http://电脑局域网IP:8000/app-ui` 展示 Web 演示页。

## 录制前准备

1. 后端启动成功，并确认 `http://127.0.0.1:8000/health` 返回 `{"status":"ok"}`。
2. 手机和电脑连接同一个 Wi-Fi。
3. 准备至少两个测试资料：一个 PDF 或 Word，一个音频或视频。
4. 提前创建或准备一个知识空间，避免录制时等待太久。
5. 如果要展示音视频转写，最好提前上传好音视频，因为首次加载模型可能比较慢。

## 分镜脚本

### 0:00 到 0:15 开场

画面：打开 MindSpace 首页。

旁白：

大家好，我们的项目叫 MindSpace 知识空间。它解决的问题是：学习和工作资料越来越多，PDF、Word、笔记、录音和视频散落在不同地方，想找一个知识点时，经常需要反复翻文件、拖进度条，效率很低。MindSpace 希望把这些资料变成一个可以搜索、可以定位来源的知识空间。

### 0:15 到 0:35 创建知识空间

画面：新建一个空间，例如“高数复习”或“黑客松资料”。

旁白：

首先，用户可以创建不同的知识空间。比如我这里创建一个课程复习空间，用来管理同一类资料。每个空间下面还可以继续创建文件夹，方便把讲义、笔记、录音或视频分门别类保存。

### 0:35 到 1:05 上传并解析资料

画面：进入空间，创建文件夹，点击上传资料，选择 PDF、Word 或 TXT 文件。

旁白：

接下来上传资料。MindSpace 支持 PDF、Word、TXT、Markdown，也支持音频和视频。上传后，后端会自动解析内容，把长文档切成较短的片段，并且保留页码、段落或时间戳。这样后面搜索时，系统不仅知道命中了哪份文件，还知道具体出现在什么位置。

### 1:05 到 1:35 搜索知识点

画面：在搜索框输入一个关键词，例如“导数”“极限”“检索”“项目目标”等，展示搜索结果。

旁白：

这里演示空间搜索。我输入一个知识点，系统会返回相关片段。搜索结果里可以看到来源文件、文件夹和命中位置。它不只是返回文件名，而是直接给出上下文片段，所以用户可以快速判断这个结果是不是自己要找的内容。

### 1:35 到 2:00 打开预览和词云

画面：点击某个搜索结果或文档，展示文档预览、片段、词云。

旁白：

点击结果后，可以进入文档预览。对于 PDF，系统可以按页展示；对于文本资料，系统会展示解析后的片段。我们还做了词云功能，用来快速看出一个空间或一份资料里最常出现的关键词，帮助用户快速理解资料主题。

### 2:00 到 2:25 音视频片段展示

画面：展示已经上传并转写好的音频或视频资料，搜索其中一句话或关键词，点击播放片段。

旁白：

MindSpace 还支持音频和视频资料。系统会通过本地 faster-whisper 把音视频转写成文字，并保留起止时间。搜索到音视频内容后，可以直接定位到对应片段，在 Web 端还能点击播放这个片段。这对会议录音、课程视频和访谈资料特别有用。

### 2:25 到 2:50 技术亮点

画面：可以切到 README 或架构图，也可以继续展示应用界面。

旁白：

技术上，我们使用 FastAPI 和 SQLite 实现后端，负责资料上传、解析、存储和搜索；前端使用 Expo、React Native 和 TypeScript，支持移动端体验。搜索部分结合了中文分词、关键词扩展、同页命中和 SQLite FTS，并且可以选配 BGE-M3 做本地语义搜索。整个原型强调本地运行和来源可追溯。

### 2:50 到 3:00 收尾

画面：回到搜索结果或首页。

旁白：

总结一下，MindSpace 的核心价值是把分散资料变成可搜索、可定位、可回看的知识空间。它适合学生复习、团队资料整理、会议记录回看和多媒体学习资料管理。以上就是我们的项目演示，谢谢大家。

## 极短版台词

大家好，我们的项目是 MindSpace 知识空间。它可以把 PDF、Word、笔记、音频和视频资料统一放进一个空间里，自动解析成可搜索片段。用户搜索知识点时，系统会返回命中的原文、文件名、页码段落或音视频时间戳，而不是只返回一个文件名。后端使用 FastAPI 和 SQLite，支持中文分词、近义词扩展、同页命中，并可选接入 BGE-M3 语义检索。音视频资料会通过 faster-whisper 转写成文字，方便直接搜索和定位片段。MindSpace 的目标是让学习资料和工作资料从普通文件夹变成可检索、可追溯的个人知识空间。
